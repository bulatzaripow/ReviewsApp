## Изменения
- На странице с отзывами добавлены: `аватар`, `имя пользователя`, `рейтинг` и `фотографии товара`
- Добавлена ячейка с общим количеством отзывов
- Устранена проблема с UI-перфомансом (асинхронная загрузка данных, убраны тяжелые операции с главного потока)
- Устранены явные утечки памяти (использование слабых (`weak`) ссылок на `self`)
- Доделана функциональность раскрытия отзыва при нажатии на кнопку "Показать полностью" (добавлен `addTarget` на кнопку)
- В json файле добавлены ссылки на аватар и фотографии товара. 
- Реализована асинхронная загрузка файлов и кеширование изображений (`NSCache`).
- Реализован `Pull-to-refresh`
- При первой загрузке отзывов добавлено состояние загрузки + использование анимации на слоях (`CALayer`)
- Весь функционал реализован без использования сторонних библиотек
